# ExplorerTabRouter (资源管理器标签路由助手)

> **为 Windows 11 文件资源管理器打造的智能单窗口标签路由工具**。  
> 解决外部打开文件夹（桌面双击、浏览器“在文件夹中显示”、命令行等）无休止弹出全新独立窗口的痛点，自动将新文件夹路由至已有资源管理器窗口的**新标签页（Tab）**中打开。

---

| **强制独立新窗口** | 需特定避让键 | 原生行为 | ✅ **支持按住 `Ctrl + Shift` 强制打开独立窗口** |
| **依赖与运行占用** | 需安装复杂平台与全局注入 | 无 | ✅ **绿色单文件（仅 25KB），极小开销** |

## 🚀 快速开始

### 1. 本地一键编译
本工具使用 Windows 11 自带的 C# 编译器（`csc.exe`）构建，**您无需安装 Visual Studio 或 .NET SDK**：
* 双击运行根目录下的 **`build.bat`**
* 编译完成后将在 `bin/` 目录下生成绿色单文件 `ExplorerTabRouter.exe`（体积仅约 25KB，且无黑色控制台弹框）。

### 2. 启用方式（二选一或同时使用）

进入 `scripts/` 文件夹：

* **方式一：启用文件夹关联路由（推荐）**
  * 双击运行 `一键启用-路由模式.bat`
  * 外部双击文件夹或应用程序调用打开文件夹时，系统将直接调用 `ExplorerTabRouter.exe` 路由到现有窗口。
  * **完全免常驻后台，随调随走，0 内存占用**。

* **方式二：启用开机自启后台守护**
  * 双击运行 `一键启用-开机自启后台守护.bat`
  * 程序将在系统托盘（右下角）常驻守护，即使某些第三方软件绕过注册表直接唤起 `explorer.exe`，也能自动捕获并无缝合并为 Tab。
  * 右键托盘图标可进行“快速新建标签”、“开机自启开关”、“临时暂停路由”等操作。

### 3. 一键还原与卸载
若您希望彻底恢复系统出厂默认行为：
* 双击运行 `scripts/一键完全卸载与还原.bat`
* 工具将自动清除注册表自定义项并停止守护进程，完全恢复系统原生行为。

## 💡 使用技巧

1. **手动拖出 Tab 拆分独立窗口**：
   在已有标签页的 Explorer 窗口中，用鼠标左键拖住任意一个 Tab 拖到窗口外松开，系统将正常将其分离为全新的独立窗口（绝不会被强行抓回！）。
2. **临时强制新窗口打开**：
   按住 **`Ctrl + Shift`** 键不放，再双击文件夹，本工具会自动放行并直接以全新独立窗口打开。
3. **命令行调用**：
   ```bash
   ExplorerTabRouter.exe "C:\Your\Folder\Path"
   ```
