# ExplorerTabRouter (资源管理器标签路由助手)

> **为 Windows 11 文件资源管理器打造的智能单窗口标签路由工具**。  
> 解决外部打开文件夹（桌面双击、浏览器“在文件夹中显示”、命令行等）无休止弹出全新独立窗口的痛点，自动将新文件夹路由至已有资源管理器窗口的**新标签页（Tab）**中打开。

---

## 🌟 核心特性与对比

| 对比项 | 传统社区 Mod（如 Windhawk Mod） | 原生 Windows 11 | **ExplorerTabRouter (本项目)** |
| :--- | :--- | :--- | :--- |
| **外部打开合并为 Tab** | ✅ 支持 | ❌ 不支持（每个文件夹弹新窗口） | ✅ **完全支持，自动路由为新 Tab** |
| **标签页向外拖出拆分 (Tear-off)** | ❌ **严重失效（被强制抓回，拖不出来）** | ✅ 支持 | ✅ **完美原生保留，自由拖拽拆分窗口** |
| **智能去重** | ❌ 重复打开多个同名标签 | ❌ 重复打开多个独立窗口 | ✅ **自动识别已有 Tab 并直接切换激活** |
| **强制独立新窗口** | 需特定避让键 | 原生行为 | ✅ **支持按住 `Ctrl + Shift` 强制打开独立窗口** |
| **依赖与运行占用** | 需安装复杂平台与全局注入 | 无 | ✅ **绿色单文件（仅 25KB），极小开销** |
| **卸载与系统安全** | 较复杂 | 无需 | ✅ **一键还原系统原生出厂默认，零残留** |

## 🚀 快速开始与使用

### 1. 唯一主程序（开箱即用，推荐 ⭐）
直接双击根目录下的 **`ExplorerTabRouter.exe`**：
* **默认开机自启**：首次双击自动配置当前用户开机启动项，开机即可在后台守护，无需手动配置。
* **常驻托盘守护**：自动在系统右下角托盘驻留，展示专门设计的极简单线文件夹图标，全自动捕获外部文件夹打开并合并到已有窗口的新标签（Tab）中。
* **托盘右键菜单**：随时可右键托盘图标进行“开机自动启动开关”、“注册文件夹打开关联”、“新建标签页”、“退出”等管理。

### 2. 备用管理脚本 (`scripts/` 目录)
`scripts/` 文件夹完整保留，供高级选项或排查时备用：
* `运行状态检查.bat`：快速检查守护进程状态与注册表项。
* `停止后台守护.bat`：临时退出守护进程。
* `一键完全卸载与还原.bat`：一键清理所有开机启动项与自定义注册表，恢复系统原生默认状态。

### 3. 本地一键编译 (若修改源码)
双击运行根目录下的 **`build.bat`**，将自动编译生成带有内置图标的 `ExplorerTabRouter.exe` 到根目录（并同步备份至 `bin/`）。

## 💡 使用技巧

1. **手动拖出 Tab 拆分独立窗口**：
   在已有标签页的 Explorer 窗口中，用鼠标左键拖住任意一个 Tab 拖到窗口外松开，系统将正常将其分离为全新的独立窗口（绝不会被强行抓回！）。
2. **临时强制新窗口打开**：
   按住 **`Ctrl + Shift`** 键不放，再双击文件夹，本工具会自动放行并直接以全新独立窗口打开。
3. **命令行调用**：
   ```bash
   ExplorerTabRouter.exe "C:\Your\Folder\Path"
   ```
